## ⚡ अपनी डिटेल्स कैसे कस्टमाइज़ करें (How to Customize)

सिर्फ `assets/js/data.js` फाइल खोलें:

1. **अपना नाम व बायो बदलें:**
   ```javascript
   personal: {
     name: "Aman Sharma", // अपना नाम डालें
     title: "Full-Stack Web Developer & Meta Ads Specialist",
     email: "contact@yourdomain.com",
     phone: "+91 98765 43210",
     whatsappNumber: "919876543210", // कंट्री कोड के साथ बिना '+' के
     ...
   }
   ```
2. **अपने WhatsApp नंबर को अपडेट करें:**
   - `whatsappNumber: "91XXXXXXXXXX"` में अपना नंबर डालते ही पूरी वेबसाइट के सभी WhatsApp बटन्स आपके नंबर से कनेक्ट हो जाएंगे!
3. **प्रोजेक्ट्स या एड्स के आंकड़े बदलें:**
   - `portfolioData.projects` में जाकर आप अपने रियल प्रोजेक्ट्स और स्क्रीनशॉट्स के लिंक लगा सकते हैं।
